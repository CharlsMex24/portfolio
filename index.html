Ask my portfolio

Ask anything about my work. Claude answers only from a short knowledge base about me, and every claim has to point to a quote. A verifier checks each quote before you see it.

  1. Your question goes to a small server that holds the API key, so it never reaches the browser.
  2. Claude gets the question plus 21 short passages about me, with citations turned on.
  3. Each sentence of the answer comes back marked with the passage it quotes.
  4. The verifier looks for every quote in the passages. What it can't find is dropped, and if nothing is left you get no answer instead of a made-up one.
